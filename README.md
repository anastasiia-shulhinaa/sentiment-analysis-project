# Визначення тональності текстових відгуків (positive / negative)

Навчальний проєкт з дисципліни «Нейронні мережі». Бінарна класифікація тональності коротких рецензій на фільми
(Rotten Tomatoes, Pang & Lee, 2005) і порівняння чотирьох підходів різної складності:
TF-IDF + логістична регресія, FastText-style (середнє embeddings), BiGRU та DistilBERT (fine-tuning).

## Структура

| Шлях | Вміст |
|---|---|
| `sentiment.ipynb` | увесь код (EDA → 4 моделі → аналіз) з виводами запуску на Kaggle |
| `configs/config.json` | усі гіперпараметри та сітки (`CFG`) |
| `configs/best_configs.json` | конфігурації, обрані за validation |
| `configs/environment.json` | версії бібліотек і GPU |

| `results/hyperparameter_experiments.csv` | таблиця експериментів з гіперпараметрами |
| `results/final_metrics.csv`, `sample_efficiency.csv`, `error_rates_by_group.csv` | підсумкові таблиці |
| `results/figures/` | графіки (EDA, гіперпараметри, збіжність, PR-криві, матриці помилок, вибіркова ефективність) |
| `report/project_Shulhina.docx` | технічний звіт |

## Як відтворити

1. Відкрити `sentiment.ipynb` на Kaggle (GPU T4, Internet увімкнено) або локально з GPU.
2. `pip install -r requirements.txt` (на Kaggle це робить перша комірка).
3. Run All — близько 40 хвилин на одній T4. Результати й конфігурації запишуться в `results/` і `configs/`.

Протокол: офіційний поділ train 8530 / validation 1066 / test 1066; кожна конфігурація × 3 seed (1, 2, 42);
вибір за середнім val F1; test використовується лише для фінальної оцінки обраних конфігурацій.

## Результати (test, mean ± std за 3 seed)

| Модель | Accuracy | F1 | AP | Навчання, с | Параметрів |
|---|---:|---:|---:|---:|---:|
| TF-IDF + LogReg | 0.788 ± 0.000 | 0.787 ± 0.000 | 0.869 | 0.6 (CPU) | 24 084 |
| FastText-style | 0.774 ± 0.004 | 0.773 ± 0.005 | 0.862 | 8.2 | 898 302 |
| BiGRU | 0.740 ± 0.002 | 0.747 ± 0.005 | 0.823 | 14.3 | 1 224 322 |
| **DistilBERT** | **0.837 ± 0.017** | **0.836 ± 0.018** | **0.922** | 43.0 | 66 955 010 |

## Висновки

- DistilBERT — найкращий і значуще кращий за TF-IDF (+4.9 п.п. F1) та BiGRU (+8.9 п.п.); на 5% train (426 прикладів)
  він майже досягає TF-IDF на повному train.
- TF-IDF — сильний baseline: моделі, що навчаються з нуля (FastText, BiGRU), його не перевершили.
- Врахування порядку слів (BiGRU) без передтренування не дало переваги над усередненням embeddings.
- Найскладніші для всіх моделей — речення з контрастом (but, however…), іронія та, ймовірно, шум у мітках.
